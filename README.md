# 📦 Sistema de Controle de Vendas e Parcelamentos

> Projeto em desenvolvimento criado para resolver uma necessidade real
> de uma pequena comerciante.

## 📖 Sobre o projeto

Este projeto está sendo desenvolvido em **Python** com o objetivo de
facilitar o controle de vendas realizadas à vista, fiadas e parceladas.

A ideia surgiu a partir da rotina de uma comerciante que realizava todo
esse controle manualmente. O sistema busca organizar clientes, produtos,
parcelas e pagamentos de forma simples e prática.

Além de resolver um problema real, este projeto faz parte do meu
processo de aprendizado em desenvolvimento de software.

------------------------------------------------------------------------

## 🎯 Objetivos

-   Cadastro de clientes
-   Cadastro de produtos
-   Registro de vendas
-   Controle de vendas fiadas
-   Controle de parcelamentos
-   Registro de pagamentos
-   Marcação automática de parcelas quitadas
-   Consulta do saldo devedor por cliente
-   Histórico de compras
